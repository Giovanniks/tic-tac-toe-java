# tic-tac-toe-java
Um jogo simples de Jogo da Velha (TicTacToe) feito em Java para correr no terminal.

### Pré-requisitos
- JDK do Java instalado (versão 8 ou superior)

### 🎮 Como Jogar
- O jogo é jogado numa grelha 3x3.

- Os jogadores alternam entre as marcas X e O.

- Digite o número da linha (0, 1 ou 2) e da coluna (0, 1 ou 2) para fazer a sua jogada.

- O primeiro a alinhar 3 símbolos na horizontal, vertical ou diagonal vence!
